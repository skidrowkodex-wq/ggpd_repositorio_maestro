05

Hub de Ingesta Inteligente & Motor de Remediación

10 / 12
📐 Índice OTQR (Overall Technical Quality Rate)
OTQR = (Filas Válidas / Total Filas) × 100%
Si OTQR = 100%: archivo procesado íntegramente.
Si OTQR < 100%: se segregan errores con planilla descargable de corrección celda por celda.
📝
Formulario Web Reactivo
Carga manual directa desde navegador o móvil con listas desplegables institucionales vinculadas a catálogos MDM.
📊
Ingesta Masiva Excel
Carga de la plantilla oficial .xlsx descargada del sistema con validación sintáctica fila por fila.
🟢 Bandeja de Conformidad
Las filas válidas se persisten inmediatamente en la base de datos Supabase y se archivan en la carpeta correspondiente del Data Lake Google Drive.
🔴 Bandeja de Remediación
Las filas con errores generan una planilla Excel de corrección con comentarios en rojo indicando celda y motivo. Se crea tarea automática en SCMTP para seguimiento.
