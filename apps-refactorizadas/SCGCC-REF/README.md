# SCGCC V1.0 — Seguimiento y Control de Gestión de Correspondencia Corporativa
### CORPOELEC — Gerencia General de Planificación y Desarrollo (GGPD)

Sistema estratégico para la radicación digital, triaje inteligente, trazabilidad perentoria de SLAs y derivación de tareas técnicas para la correspondencia institucional recibida y emitida en el Despacho de la GGPD.

---

## 🛡️ Estándar de Grado Industrial SEN
- **ISO/IEC 27001:2022:** Seguridad en InsForge BaaS / PostgreSQL, RLS y autenticación de Zona Segura.
- **ISO 15489-1:2016:** Gestión integral de documentos y registros institucionales.
- **ISO 8000-110:** Calidad e integridad sintáctica/semántica de datos de correspondencia.
- **OWASP ASVS v4.0 Level 2:** Blindaje contra inyección y control de acceso robusto.
- **ISACA COBIT 2019 (MEA02):** Auditoría inmutable de eventos de radicación y despacho.

---

## 🚀 Despliegue y Ejecución
- **Puerto:** `3006`
- **Desarrollo:** `npm run dev`
- **Compilación de Producción:** `npm run build`
- **Servidor Local CJS:** `node dist/server.cjs` (o `python3 serve_all.py` desde el Repositorio Maestro).
